# Contributing

Thank you for wanting to help with Selah.

## Bug reports and ideas

Open an [issue](https://github.com/JDT12/selah/issues). For a bug, say what you did, what happened and what you
expected, with the version (Settings → About) and whether it's Selah Desktop or Selah Cloud. Please leave out names,
notes and anything private, in text and in screenshots.

## How the code gets here

This repository receives one commit per beta and release: development happens in a private repository, and each
version is published here as a whole. So:

- **Pull requests** are welcome, but they aren't merged here directly. A change that's accepted is brought into the
  private repository, credited to you in the commit and CHANGELOG.md, and appears here in the next version. The pull
  request is then closed with a link to it.
- Keep a pull request to one change, and describe why it's needed. For anything large, open an issue first so we can
  agree on the approach.
- Write the way the code and the guides already do: plain words, American spelling, and comments that say why.
