# Selah

Selah is free software for pastors, teachers and seminary students: notes, Bible study, teaching and preaching,
slides and a sermon bank, in one place. It comes three ways.

| | **Selah Desktop** | **Selah Cloud** | **Selah Ministry** |
| --- | --- | --- | --- |
| For | One person on a Windows PC, Mac or Linux computer | You (or your family), on your own server | A church, a class or a group of people, each with their own Selah |
| Needs | Windows 10 or 11, macOS 12 or later, or 64-bit Linux | A small Linux server and an address (`selah.example.org`) | A Linux server and a domain for everyone's Selahs |
| Sign-in | None (optional PIN, Windows Hello or Touch ID lock) | Username or email, password and two-step sign-in | Username or email, password and two-step sign-in |
| Phone and other computers | No (one PC; export notes, lessons, sermons and slides to share them) | Yes: any browser, Selah Desktop and the Selah apps for iPhone, iPad and Android | Yes: any browser, Selah Desktop and the Selah apps |
| Sharing between people | No | No (export or print) | Yes |
| Backups | Automatic, to a folder you choose (OneDrive, iCloud Drive, Dropbox) | Every night, off the server (OneDrive, S3, WebDAV) | Every night, all Selahs, by the server |
| Updates | By themselves | One click in Settings | From the admin console |
| Setup | Run the installer | One command on the server | One command on the server |

Moving between them: a backup file from one opens in another (Settings → Data & backup).
