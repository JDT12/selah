# Security

Selah keeps people's notes, prayers and journals, so security problems matter. Please don't report one in a public
issue.

## Reporting a problem

Use GitHub's private reporting: **Security → Report a vulnerability** on this repository. Include what you found,
how to reproduce it, which version (Settings → About shows it) and whether it affects Selah Desktop, Selah Cloud or
both. You'll get an answer within a week.

Please don't test against a Selah you don't run yourself, and don't access anyone's data. Install your own (see
[docs/](docs/index.md)) to try things.

## What's supported

The newest release gets fixes. Selah Desktop updates itself; Selah Cloud servers update with `bash scripts/update.sh`.
A fix for a serious problem is released as soon as it's ready and noted in CHANGELOG.md.
